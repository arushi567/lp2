🔷 UNIT I: INTRODUCTION TO ARTIFICIAL INTELLIGENCE
1. What is Artificial Intelligence (AI)?

Artificial Intelligence is the field of computer science that focuses on creating systems that can perform tasks that typically require human intelligence.

Core Idea:

AI = Machines that can think, learn, and make decisions like humans (or even better in specific tasks)

Capabilities of AI:
Learning from data
Reasoning and problem-solving
Understanding language
Perception (vision, speech)
Decision-making under uncertainty
Real-World Examples:
Voice Assistants (Siri, Alexa)
Recommendation Systems (Netflix, YouTube)
Self-driving cars
Chatbots
Fraud detection systems

Field	Contribution

3. Intelligent Agents
Definition:

An agent is anything that:

Perceives its environment through sensors and acts upon it using actuators

Structure of an Agent:
Sensors → Take input from environment
Actuators → Perform actions
Examples:
Agent	Sensors	Actuators
Human	Eyes, ears	Hands, legs
Robot	Camera, sensors	Wheels, arms

4. Rational Agent
Definition:

A rational agent is one that:

Always chooses the action that maximizes its performance measure, based on available information.

Important Points:
Rational ≠ Perfect
Works with limited knowledge
Makes the best possible decision at that moment

🔷 UNIT II: PROBLEM SOLVING & SEARCH
1. State Space Representation
Key Terms:
State → A configuration of the system
Initial State → Starting point
Goal State → Desired outcome
Operators → Actions that move between states
State Space → All possible states
2. Breadth First Search (BFS)
Idea:

Explore level by level

Working:
Uses Queue (FIFO)
Expands all nodes at current depth before going deeper
Example:
A → B, C
B → D, E

Traversal:
A → B → C → D → E

Properties:
Complete: ✅ Yes
Optimal: ✅ Yes (if cost is same)
Time Complexity: O(b^d)
Space Complexity: O(b^d)
🔥 Crucial Insight (VERY IMPORTANT):

BFS stores all nodes in memory

Example:

Branching factor = 10
Depth = 10
Nodes = 10^10

👉 Requires huge memory (GBs) → biggest drawback

3. Depth First Search (DFS)
Idea:

Explore deepest path first

Working:
Uses Stack or Recursion
Properties:
Complete: ❌ No (in infinite space)
Optimal: ❌ No
Time Complexity: O(b^m)
Space Complexity: O(b × m)
Key Insight:

DFS uses very little memory, but:

Can go in wrong direction forever
May miss shortest path
4. BFS vs DFS (DETAILED COMPARISON)
Feature	BFS	DFS
Strategy	Level-wise	Deep-first
Data Structure	Queue	Stack
Completeness	Yes	No
Optimality	Yes	No
Time	O(b^d)	O(b^m)
Space	O(b^d) (Huge)	O(b×m) (Small)
🔥 Viva Insight:

“The real villain in AI search is MEMORY”

BFS fails due to memory
DFS fails due to wrong path

👉 This is why we need better algorithms

5. Depth Limited Search (DLS)
Definition:

DFS with a depth limit (L)

Logic:
Nodes beyond depth L are not explored
Treated as leaf nodes
Why Needed:

Solves infinite loop problem of DFS

Problem:

If goal is deeper than limit:

DLS will fail (Not Complete)

Complexity:
Time: O(b^L)
Space: O(b × L)
6. Iterative Deepening DFS (IDDFS)
Idea:

Run DLS multiple times:

L = 0 → 1 → 2 → 3 … until goal found
Why it’s Powerful:
Property	Value
Completeness	✅ Yes
Optimality	✅ Yes
Memory	Low (like DFS)
🔥 IMPORTANT INTUITION (DON’T SKIP):
“Isn’t repeating work wasteful?”

At first glance:

You keep re-exploring upper levels → seems inefficient

But reality:

Most nodes are at deepest level
Re-exploration cost is very small (~11%)

👉 So IDDFS is actually very efficient

Final Conclusion:

IDDFS = Best of BFS + DFS

7. Heuristic Function
Definition:

A heuristic function:

h(n) = estimated cost from node n to goal

Types:
1. Admissible Heuristic
Never overestimates
Guarantees optimal solution
2. Consistent Heuristic
Follows triangle inequality
Ensures stability in A*
8. A* Algorithm

Uses evaluation function:

f(n)=g(n)+h(n)

Where:

g(n) → cost from start to current node
h(n) → estimated cost to goal
Key Idea:

Choose node with minimum f(n)

Why Important:
Most efficient path-finding algorithm
Used in GPS, games, robotics
9. Local Search Algorithms
Idea:

Work with a single current state

Examples:
Hill Climbing
Simulated Annealing

🔷 UNIT IV: KNOWLEDGE REPRESENTATION
1. Propositional Logic (PL)

2. First Order Logic (FOL) (VERY IMPORTANT)
Components:
Predicates
Variables
Constants
Quantifiers
Quantifiers:
∀ → For all
∃ → There exists
English → FOL Conversion (STEP-BY-STEP)
Example 1:

“All humans are mortal”

Breakdown:

For every x
If x is human → x is mortal

Final:
∀x (Human(x) → Mortal(x))

Example 2:

“Some students are intelligent”

Breakdown:

There exists x
Student(x) AND Intelligent(x)

Final:
∃x (Student(x) ∧ Intelligent(x))

Example 3:

“John has a brother who is a doctor”

Final:
∃x (Brother(x, John) ∧ Doctor(x))

❗ Common Mistake (VERY IMPORTANT)

Wrong:
∀x (Human(x) ∧ Mortal(x))

Meaning:
Everything is human and mortal ❌

Correct:
∀x (Human(x) → Mortal(x)) ✅

🔷 UNIT V: REASONING
1. Inference

Process of deriving new facts

2. Forward vs Backward Chaining (DETAILED)
Forward Chaining (Data-driven)

Process:

Start with known facts
Apply rules → generate new facts

Example:
A → B
B → C

If A is true → derive C

Backward Chaining (Goal-driven)

Process:

Start with goal
Find rules that lead to goal
Check if conditions are true
Comparison:
Feature	Forward	Backward
Direction	Data → Goal	Goal → Data
Use	Monitoring	Diagnosis
