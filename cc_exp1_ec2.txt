------------------------------------------------------------------------------------------------------------------------

from flask import Flask, render_template, request, redirect

app = Flask(__name__)

notes = []

@app.route("/")
def home():
    return render_template("index.html", notes=notes)

@app.route("/add", methods=["POST"])
def add():
    note = request.form.get("note")
    if note:
        notes.append(note)
    return redirect("/")

@app.route("/delete/<int:index>")
def delete(index):
    if 0 <= index < len(notes):
        notes.pop(index)
    return redirect("/")

app.run(host="0.0.0.0", port=5000)


-----------------------------------------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------------------------------------


👉 Why each part exists:

notes = [] → stores data in memory
/ → homepage
/add → handles form submission
/delete → removes item
0.0.0.0 → allows public access
5000 → Flask default dev port

☁️ 1. CLOUD COMPUTING (CORE THEORY)
📌 Definition

Cloud computing is:

The delivery of computing services like servers, storage, databases, networking, and software over the internet (“the cloud”) on a pay-as-you-use basis.

📌 Key Characteristics
On-demand self service → You can create servers anytime
Broad network access → Access via internet
Resource pooling → Shared infrastructure among users
Scalability → Increase/decrease resources anytime
Pay-as-you-go → Pay only for usage
📌 Types of Cloud Models
1. Public Cloud
Resources shared across users
Example: AWS, Azure
2. Private Cloud
Dedicated to one organization
3. Hybrid Cloud
Mix of public + private
📌 Service Models
1. IaaS (Infrastructure as a Service)

You get virtual machines, storage, networks

✔ Example: EC2

2. PaaS (Platform as a Service)

Platform to deploy apps without managing OS

3. SaaS (Software as a Service)

Ready-made software
