public class LibraryController {
    
    @AuraEnabled
    public static List<Book__c> getBooks() {
        return [SELECT Id, Name, Author__c, Genre__c, Status__c FROM Book__c ORDER BY CreatedDate DESC LIMIT 50];
    }

    @AuraEnabled
    public static void addBook(String title, String author, String genre) {
        Book__c newBook = new Book__c(Name = title, Author__c = author, Genre__c = genre, Status__c = 'Available');
        insert newBook;
    }

    @AuraEnabled
    public static void toggleBookStatus(Id bookId, String currentStatus) {
        String newStatus = (currentStatus == 'Available') ? 'Checked Out' : 'Available';
        update new Book__c(Id = bookId, Status__c = newStatus);
    }

    @AuraEnabled
    public static void deleteBook(Id bookId) {
        delete new Book__c(Id = bookId);
    }
}

### 🧠 Part 2: The JavaScript Logic (CONTROLLER)
Click the **CONTROLLER** button on the right side of Dev Console. Paste this:

----------------------------------------------------------------------------------------------------------------------
----------------------------------------------------------------------------------------------------------------------


({
    doInit : function(component, event, helper) {
        var action = component.get("c.getBooks");
        action.setCallback(this, function(response) {
            if(response.getState() === "SUCCESS") {
                component.set("v.bookList", response.getReturnValue());
            }
        });
        $A.enqueueAction(action);
    },
    
    saveBook : function(component, event, helper) {
        var title = component.get("v.newTitle");
        var author = component.get("v.newAuthor");
        var genre = component.get("v.newGenre");
        
        if(!title || !author) { 
            alert('Title and Author are required!'); 
            return; 
        }
        
        var action = component.get("c.addBook");
        action.setParams({ "title": title, "author": author, "genre": genre });
        action.setCallback(this, function(response) {
            if(response.getState() === "SUCCESS") {
                component.set("v.newTitle", "");
                component.set("v.newAuthor", "");
                component.set("v.newGenre", "");
                // Refresh the list
                var refresh = component.get("c.doInit");
                $A.enqueueAction(refresh);
            }
        });
        $A.enqueueAction(action);
    },
    
    changeStatus : function(component, event, helper) {
        // We passed both ID and Status in the button value, separated by a pipe "|"
        var values = event.getSource().get("v.value").split("|");
        var bookId = values[0];
        var currentStatus = values[1];
        
        var action = component.get("c.toggleBookStatus");
        action.setParams({ "bookId": bookId, "currentStatus": currentStatus });
        action.setCallback(this, function(response) {
            var refresh = component.get("c.doInit");
            $A.enqueueAction(refresh);
        });
        $A.enqueueAction(action);
    },
    
    remove : function(component, event, helper) {
        var recId = event.getSource().get("v.value");
        var action = component.get("c.deleteBook");
        action.setParams({ "bookId": recId });
        action.setCallback(this, function(response) {
            var refresh = component.get("c.doInit");
            $A.enqueueAction(refresh);
        });
        $A.enqueueAction(action);
    }
})

# 🧱 LINE-BY-LINE EXPLANATION (APEX CONTROLLER)

---

## 🔹 Aura Annotation

```apex
@AuraEnabled
```

👉 Tells Salesforce: "Allow the frontend Lightning component to use this method." Without this, the UI is blocked for security.

---

## 🔹 Load Books (Read)

```apex
public static List<Book__c> getBooks()
return [SELECT Id, Name, Author__c, Genre__c, Status__c FROM Book__c ORDER BY CreatedDate DESC LIMIT 50];
```

👉 Runs SOQL query on our custom object (`__c` means custom). Fetches the 50 newest books.

---

## 🔹 Add Book (Create)

```apex
Book__c newBook = new Book__c(Name = title, ... Status__c = 'Available');
insert newBook;
```

👉 Creates a new record based on typed input and permanently saves (`insert`) it to the database.

---

## 🔹 Toggle Status (Update)

```apex
String newStatus = (currentStatus == 'Available') ? 'Checked Out' : 'Available';
update new Book__c(Id = bookId, Status__c = newStatus);
```

👉 Uses a quick "if/else" logic. If available, make it checked out (and vice versa). Then `update` the database.

---

## 🔹 Delete Book (Delete)

```apex
delete new Book__c(Id = bookId);
```

👉 Finds the book by its unique ID and removes it entirely from Salesforce.

# 🎨 LIGHTNING COMPONENT EXPLANATION (.CMP & .JS)

---

## 🔹 Component Setup

```html
<aura:component controller="LibraryController" ... >
```

👉 Links the UI directly to our Apex backend class.

---

## 🔹 Variables (Attributes)

```html
<aura:attribute name="bookList" type="List" />
```

👉 Holds the data on the screen. `bookList` stores the array of books. `newTitle` stores what the user types.

---

## 🔹 Initialization

```html
<aura:handler name="init" value="{!this}" action="{!c.doInit}" />
```

👉 As soon as the app opens (`init`), run the `doInit` JavaScript function to load the books.

---

## 🔹 Form Inputs & Buttons

```html
<lightning:input value="{!v.newTitle}" />
<lightning:button onclick="{!c.saveBook}" />
```

👉 `v.` means Value (talks to the HTML). `c.` means Controller (talks to JavaScript). Clicking the button triggers JS.

---

## 🔹 JavaScript Action Calling

```javascript
var action = component.get("c.addBook");
```

👉 JavaScript prepares to call the Apex backend.

---

## 🔹 Server Call & Refresh

```javascript
$A.enqueueAction(action);
var refresh = component.get("c.doInit");
$A.enqueueAction(refresh);
```

👉 Fires the request to the server. If successful, it automatically triggers `doInit` again to refresh the screen instantly!

# ⚙️ 3. AURA FRAMEWORK

👉 The specific code structure for this Lightning Component.

Contains:

* **.cmp File:** The HTML markup.
* **.js Controller:** The client-side logic handling clicks and server requests.
* **Apex Class:** The server-side logic handling the actual database saving.

# 🧾 VIVA ANSWERS

---

### 1. What is Salesforce Lightning?

The modern, component-based frontend framework and UI for Salesforce.

---

### 2. What is a Custom Object?

A database table created by a developer to store custom data, identified by the `__c` suffix.

---

### 3. What does @AuraEnabled do?

It makes an Apex method accessible and visible to a Lightning Component.

---

### 4. What is the difference between v. and c. in Lightning?

`v.` refers to the View (variables/attributes in HTML), and `c.` refers to the Controller (actions in Javascript or Apex).

---

### 5. Why do we use $A.enqueueAction()?

It places the server request into a queue so Salesforce can run it asynchronously without freezing the user's screen.

---

### 6. What is the MVC pattern in this project?

Model is the `Book__c` object, View is the `.cmp` file, and Controller is the Apex class and `.js` file combined.
