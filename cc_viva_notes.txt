# ☁️ UNIT I: INTRODUCTION TO CLOUD COMPUTING

## 1. What is Cloud Computing?

Cloud Computing is the delivery of computing services like servers, storage, databases, networking, and software over the internet instead of using local machines.

### Core Idea:

You don’t own infrastructure → you *rent it on demand*

---

## 2. Importance of Cloud Computing

Before cloud:

* Companies had physical servers
* High maintenance cost
* Limited scalability

After cloud:

* Instant scaling
* Low cost
* Global access

---

## 3. Characteristics of Cloud Computing (VERY IMPORTANT)

### 1. On-Demand Self Service

Users can create resources anytime (no admin needed)

### 2. Broad Network Access

Accessible via internet anywhere

### 3. Resource Pooling

Shared infrastructure among many users

### 4. Rapid Elasticity

Scale up/down instantly

### 5. Measured Service

Pay only for usage

---

## 4. Pros and Cons of Cloud Computing

### Advantages:

* Low cost
* Scalable
* No hardware needed
* Easy maintenance
* High availability

### Disadvantages:

* Internet dependency
* Security concerns
* Vendor lock-in
* Less control over hardware

---

## 5. Migrating into Cloud

Moving applications/data from local system → cloud

### Why migrate?

* Better performance
* Lower cost
* Scalability

---

## 6. Seven-Step Migration Model (IMPORTANT)

1. **Assess** current system
2. **Select** applications to migrate
3. **Choose cloud provider** (AWS/Azure)
4. **Plan migration strategy**
5. **Migrate data & apps**
6. **Test system**
7. **Optimize & monitor**

---

## 7. Trends in Cloud Computing

* AI + Cloud integration
* Serverless computing
* Edge computing
* Containerization (Docker, Kubernetes)
* Multi-cloud systems

---

## 8. Cloud Service Models (VERY IMPORTANT)

### 1. SaaS (Software as a Service)

Ready-to-use software

Examples:

* Gmail
* Google Docs

👉 User: just uses software

---

### 2. PaaS (Platform as a Service)

Platform to build apps

Examples:

* Google App Engine
* Heroku

👉 Developer: writes code only

---

### 3. IaaS (Infrastructure as a Service)

Provides virtual machines, storage

Example:

* AWS EC2

👉 You manage OS + apps

---

## 9. Storage in Cloud

Cloud storage = storing data on remote servers

Examples:

* Google Drive
* AWS S3

---

## 10. Cloud Architecture

### Layers:

1. Frontend (User Interface)
2. Backend (Servers)
3. Cloud Infrastructure
4. Network layer

---

## 11. Cloud Deployment Models

### 1. Public Cloud

AWS, Azure (shared system)

### 2. Private Cloud

Single organization

### 3. Hybrid Cloud

Mix of both

---

# ☁️ UNIT III: VIRTUALIZATION IN CLOUD COMPUTING

---

## 1. What is Virtualization?

Creating virtual versions of:

* Servers
* OS
* Storage
* Networks

---

## 2. Why Virtualization?

* Better resource utilization
* Cost reduction
* Isolation between systems

---

## 3. Types of Virtualization

* Server virtualization
* Storage virtualization
* Network virtualization
* Desktop virtualization

---

## 4. Virtualization Architecture

Hypervisor (VERY IMPORTANT)

### Types:

* Type 1 (Bare metal)
* Type 2 (Hosted)

---

## 5. Virtual Clustering

Multiple virtual machines working as one system

---

## 6. Pitfalls of Virtualization

* Performance overhead
* Security risks
* Complex management

---

## 7. Grid vs Cloud vs Virtualization

| Concept        | Meaning                  |
| -------------- | ------------------------ |
| Grid           | Distributed computing    |
| Cloud          | On-demand services       |
| Virtualization | Creating virtual systems |

---

## 8. CPU Virtualization

Multiple OS share same CPU

---

## 9. Network & Storage Virtualization

* Virtual networks created
* Storage pooled and shared

---

## CASE STUDIES
